# crypto-candle-model

**다음 1시간봉에서 장대 양봉 / 장대 음봉이 나올지 맞히는 AI 모델 — 그리고 "크기는 맞히고, 방향은 못 맞힌다"는 결론**

> Can an ML model predict whether the next 1-hour candle on Binance perpetual futures will be a large bullish or bearish candle? Across 32 coins, a logistic model **predicts candle size** beyond a volatility + time-of-day baseline (pre-registered test passed), but **cannot predict candle color** better than a coin flip, and following the first intrabar move during forecast "storm" hours loses money even before fees. All rules and pass criteria were written down before looking at test results.

---

## 한 줄 결론

| 질문 | 결과 |
|---|---|
| 다음 1시간봉이 **장대봉**일까? (크기) | ✅ **맞힐 수 있다** — 최근 변동성 + 시간대가 가장 큰 단서, 거래량이 작지만 진짜 정보를 더함 (32종목 합격) |
| 장대봉이라면 **양봉일까 음봉일까?** (방향) | ❌ **동전 던지기 수준** (AUC 0.521, 범위 아래 끝 0.500 — 불합격) |
| 폭풍(장대봉 확률 높음) 시간에 **먼저 출발한 쪽을 따라가면?** | ❌ 수수료 **전**부터 손해 (비용 후 거래당 −0.188%) |

## 설계

### 1. 정답지
| 항목 | 결정 | 이유 |
|---|---|---|
| 시간봉 | 1시간봉, 매 봉이 끝날 때마다 질문 | |
| 봉 크기 | **몸통** = \|종가 − 시가\| | 들고 있었으면 돈이 됐는지를 정하는 건 꼬리가 아니라 몸통 |
| 평소 | 그 코인의 직전 336봉(14일) 몸통 평균 | 고정 %는 코인·시기마다 뜻이 달라짐 → "평소와 다른 것"을 알아채야 의미 |
| 장대봉 | 다음 봉 몸통 ≥ 평소 × **2** | 32종목 전체 12.3%, 코인별 10.6 ~ 13.5%로 비슷 (기준이 코인 성격과 무관하게 작동) |
| 2단계 정답 | 장대봉일 때만 양봉 1 / 음봉 0 | 32종목 장대봉 중 양봉 51.0% |

### 2. 단서 (모두 지금 봉이 끝난 시각까지의 정보만)
| 묶음 | 단서 | 뜻 |
|---|---|---|
| 가격 (출렁임) | `vol_4h`, `vol_24h` | 최근 4·24봉 몸통 평균 ÷ 평소 몸통 |
| 가격 (방향) | `ret_1h`, `ret_4h`, `ret_24h` | 최근 1·4·24봉 가격 변화 ÷ 평소 몸통 |
| 거래량 | `volu_1h`, `volu_4h` | 지금 / 최근 4봉 거래량 ÷ 직전 14일 평균 (지금 봉 제외) |
| | `taker_buy` | 시장가 매수 ÷ 전체 거래량 (사는 쪽이 급했나) |
| OI | `oi_1h`, `oi_24h` | 미결제약정(코인 개수) 1·24시간 변화율 |
| 시간 | `h01`~`h23` | UTC 시각 (변경 1에서 추가) |

### 3. 검증 방식
- **사전 등록**: 정답지·단서·합격 기준을 **점수를 보기 전에** 문서로 확정. 결과를 본 뒤 기준을 바꾸지 않음
- **기간 나누기 (워크포워드)**: 공부 2023-11 ~ 2024-10 → 시험(모의고사) 2024-11 ~ 2025-10, 사이 2시간 비움
- **수능 기간(2025-11 ~ 2026-10)은 아직 열지 않음** — 최종 확인용으로 한 번만 사용 예정
- **상대**: 1단계는 "변동성 예보관"(뻔한 예상), 2단계는 "찍기"(공부 기간 양봉 비율)
- **합격**: AUC와 향상도(찍기 대비 Brier 개선) **둘 다**, **날 단위 부트스트랩 500회** 95% 범위 아래 끝이 기준 위 (같은 날 시간·코인끼리 닮아서 통째로 뽑음)
- **변경 횟수 기록**: 모의고사를 보고 바꾼 것 1회 (시간대 확인)
- 모든 코드는 일부러 신호를 심은 **가짜 데이터로 먼저 시험** — 숨긴 신호를 찾는지, 가짜 신호를 잡아내는지 확인

## 결과 (모의고사, 시험 2024-11 ~ 2025-10)

### 1단계 — BTC 하나
| 예보관 | 향상도 | AUC |
|---|---|---|
| 변동성 (상대) | +5.0% | 0.695 |
| 학생 (단서 10개) | +6.4% | 0.735 |
→ **합격** (AUC +0.040, 향상도 +1.33%p). 학생이 가장 크게 본 단서: `volu_1h`

### 변경 1 — "거래량이 아니라 시계를 본 것 아닐까?"
`volu_1h`는 하루 전체 평균 대비라, 원래 거래량이 많은 시간엔 자동으로 커짐 → 양쪽에 시간대를 똑같이 주고 다시 시험

| 장대봉이 잘 나오는 시각 (공부 기간, BTC) | |
|---|---|
| 23시 KST (14 UTC) | **28.7%** |
| 15시 KST (06 UTC) | **5.2%** |

| 예보관 | 향상도 | AUC |
|---|---|---|
| 변동성 + 시간 | **+8.4%** | 0.727 |
| 학생 + 시간 | +9.0% | 0.745 |
→ **불합격** (향상도 범위 −0.16 ~ +1.39%p). 처음의 승리는 상당 부분 **미국장 개장 시간대 효과**였음

### 1단계 — 32종목 (상대도 시간대를 앎)
| 예보관 | 향상도 | AUC |
|---|---|---|
| 변동성 + 시간 (상대) | +7.2% | 0.720 |
| **학생 + 시간** | **+7.8%** | **0.729** |
→ **합격** (AUC +0.009 [+0.008 ~ +0.011], 향상도 +0.58%p [+0.38 ~ +0.78]). 데이터가 많아지자 거래량의 작은 정보가 확실해짐. **공부 때 못 본 코인 12개에서도 이김** (0.746 → 0.754)

### 2단계 — 장대봉의 색
| 예보관 | 향상도 | AUC |
|---|---|---|
| 찍기 (상대) | 0.0% | 0.500 |
| 학생 | −0.49% | 0.521 (0.500 ~ 0.538) |
→ **불합격**. 색 맞힌 비율 51.4% (항상 양봉 찍기 50.9%). 향상도 음수 = 약한 신호에 너무 자신 있게 말함

### 연구 10 — 폭풍 속 돌파 따라가기
1단계 확률 상위 10%("폭풍") 시간에, 다음 1시간 도중 5분봉 종가가 시가에서 평소 몸통 × 0.5 이상 벗어나면 그 방향으로 진입 → 1시간 종가 청산. 왕복 비용 0.14%

| | 거래 | 비용 전 | 비용 후 | 평균 이익 / 손실 |
|---|---|---|---|---|
| 폭풍 시간 | 18,602 | −0.048% | **−0.188%** (−0.248 ~ −0.127) | +1.29% / −1.29% |
| 폭풍 아님 | 149,867 | −0.013% | −0.153% | +0.67% / −0.63% |
→ **불합격**. 예보는 맞았지만(폭풍 시간 실제 장대봉 34.8% vs 평소 9.9%), 폭풍은 **위아래 흔들림을 2배로 키울 뿐** 첫 움직임이 방향을 알려주지 않음

## 배운 점
1. **크기는 예측되고 방향은 안 된다.** 이전 연구(과열 신호, 지지저항, CVD, 롱숏비율, 오더북, 청산)까지 합쳐 열 번째 같은 결론 — 1시간~24시간 단위에서 방향은 동전 던지기
2. **진짜 상대는 "이미 아는 것"이다.** 변동성, 그리고 시간대. 이걸 이겨야 새 정보
3. **좋은 결과일수록 의심한다.** BTC 1단계 합격은 시간대 효과가 섞여 있었고, 의심을 시험으로 바꿔서 확인
4. **표본이 작으면 진짜 작은 효과도 안 보인다.** BTC 하나로는 불확실했던 거래량 효과가 32종목에선 확실
5. **"평소 대비"로 만든 단서는 처음 보는 코인에서도 통한다**
6. **예측 성공 ≠ 돈.** 크기를 맞혀도 방향이 없으면 선물 한 계좌로는 직접 수익이 안 남 → 위험 관리(레버리지 조절) 도구로 쓰임

## 한계
- 수능 기간(2025-11 ~ 2026-10)은 아직 미사용. 이전 연구들이 같은 기간을 다른 질문으로 본 적 있음 → 진짜 깨끗한 확인은 2026-11 이후
- 모델은 로지스틱 회귀 하나 (단순함을 일부러 유지)
- 비용은 바이낸스 일반 등급 테이커 0.05% + 미끄러짐 0.02% 가정. 펀딩비는 1시간 보유라 무시
- 32종목 중 다수가 2025년 이후 상장 알트
